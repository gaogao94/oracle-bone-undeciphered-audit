## 请专家看这里

本仓库有**两份材料需要具备古文字学训练的人判定**。预计耗时约一小时。

### 问题一：我那 9 条比对有没有错？

**主张**：`OBIMD`（甲骨文多模态数据集）标记为「未释字」的字形中，
有一批**其读法《甲骨文合集》已经给出**，只是甲骨文写法未进入 Unicode，数据集无法编码。
**它们不是"学界未释"，是"数据集未编码"。**

**证据**：下面 [§一](#一9-条已逐字核实编码缺失) 的 9 条。每条都取《合集》**原片释文**逐字比对，
三项标准同时满足：① 《合集》给出**可读的通用汉字**；② OBIMD 辞例与该释文**逐字吻合**；
③ 目标字的**左右邻字完全一致**。

**请回答**：这 9 条对不对？

| 可能的结论 | 后果 |
|---|---|
| 对 | 则「用 OBIMD 做未释字研究前必须先做编码缺失筛查」这条结论可被引用 |
| 第 X 条不对 | 我改（这是最有价值的结果） |
| 方法本身有问题 | 整个仓库的可靠性需重估 |

### 问题二：`gx21ndp7yy` 是已知字，还是真未释？

**主张**：<img src="glyphs/gx21ndp7yy.png" alt="字形" height="24" align="middle">（OBIMD 编号 `gx21ndp7yy`，出现 **54 次**）
是**学界真正未释**的字。

**依据**：在《合集》释文全库检索该字所在句式「王 X 叀（惠）吉」，
**X 位从未出现任何已释字**——全部是私用区码位（U+E123 九次、U+E124 六次）或缺文。
即**《合集》编者也读不出它**，只能为它造字。详见 [§二](#二-确证的真未释字1-个)。

**请回答**：

| # | 问题 |
|---|---|
| 1 | 这个字**已有公认读法**吗？（若有，请告知） |
| 2 | 若没有——**材料够不够做一篇考释**？（54 次、4 形、22 例固定套语、类组单一） |
| 3 | 要推进它，**还需要什么**？ |

**我已试过并排除的**：见 [§二](#二-确证的真未释字1-个) 的对照表
（奭、舞、木、桑、禾、米、東、朱、未、目、見、望、省、天、大、夫、文、立、余）。
**我未能给出读法**，因为形态最近的「奭」语法上不作动词，而语法位置合适的动词形态都不像。

> 请通过 [Issues](https://github.com/gaogao94/oracle-bone-undeciphered-audit/issues) 反馈。

## 关于本仓库中的字形显示

甲骨文字形**不在 Unicode 编码平面内**（OBIMD 用私有区 U+F0000 区，殷契文渊用 U+60000 区），
**无法用文本表示**。本仓库的处理方式：

| 写法 | 含义 |
|---|---|
| 行内小图 | 该未释字的**字形图**（`glyphs/`，按 OBIMD 内部编号命名） |
| `gx21ndp7yy`、`mepmffeebh` | OBIMD **内部编号**，用于指代具体字形 |
| **楷体汉字**（娩、西、丘） | 已释字的**隶定读法** |
| `⟨▢⟩` | 站点私有码位（国学大师为《合集》罕见字所造），本仓库无对应字形图 |
| 扩展区汉字（𰩶、𠦪、𡧊） | Unicode 扩展区正式字符 |

**字形图目录** [glyphs/](glyphs/)：**137 张**，覆盖正文中出现的全部可还原字形。

### 最强的一条：数据集内部不一致

第 1 条 <img src="glyphs/dsv4lhwhn7.png" alt="字形" height="18" align="middle">：
`OBIMD` 在**别处 18 次**都把同一句话、同一位置认作「**娩**」，
**独在《合集》17382 标为未释字**。这是**数据集字形分类内部不一致**的直接证据，
与「学界未释」全无关系。

### 三类机制

| 实为 | OBIMD 字表中 | 语料实例数 | 性质 |
|---|---|---|---|
| **娩** | 有 | **18** | **数据集内部不一致**（最强） |
| 西 | 有 | 62 | 数据集内部不一致 |
| 龜 | 有 | 6 | 数据集内部不一致 |
| 丘 | 有 | 6 | 数据集内部不一致 |
| 宓 | 有 | 2 | 数据集内部不一致 |
| **黃** | 有 | **0** | 字表有条目，语料零实例 |
| **安** | 有 | **0** | 字表有条目，语料零实例 |
| **豲** | **无该字形类** | — | 数据集未收录该字的字形 |

### 意义

> **任何基于 OBIMD 的未释字研究，都应先做「数据集未编码」与「学界未释」的分层，
> 否则问题集包含伪问题。**

两者性质完全不同：前者是数据工程缺陷，后者才是考释对象。

## 二、确证的真未释字（1 个）

**<img src="glyphs/gx21ndp7yy.png" alt="字形" height="22" align="middle">** — <img src="glyphs/gx21ndp7yy.png" alt="字形" height="26" align="middle">

| 项 | 内容 |
|---|---|
| OBIMD 编号 | `gx21ndp7yy` |
| 出现次数 | **54**（243 个未释字形类中列第三） |
| 字形数 | 4 |
| **类组** | **专属于「事何類」**（廪辛—康丁时期），不见于宾组、出组、黄组 |
| 涉及片 | **35 片**（见 [tier_B_plates.json](handoff/tier_B_plates.json)） |
| 前邻字 | **王**（16 次） |
| 后邻字 | **叀**（22 次） |

### 核心套语

```
貞 王 【<img src="glyphs/gx21ndp7yy.png" alt="字形" height="22" align="middle">】 叀（惠）吉
```

共 **22 例**。句式义为「王【X】，惠吉」——「惠吉」是卜辞常见的判断语
（「（此事）为宜、吉」），本字处于「王」与判断语之间，**语法位置为动词**。
同期相近句式可参：「王 賓（夙）」「王 田」「王 步」。

### 为什么认为是真未释

在《合集》释文**全库**检索「王 X 叀（惠）吉」，**X 位字符分布**：

| X 位字符 | 次数 | 性质 |
|---|---|---|
| **U+E123** | 9 | **私用区码位**（站点造字） |
| **U+E124** | 6 | **私用区码位** |
| … | 6 | 缺文 |
| ： | 4 | 属「鼎（貞）：」，非该位置 |
| 王 | 1 | 异文 |

> **50 条事何類「吉」类辞例中，该位置从未出现任何已释字。**

《合集》编者给这个字形**分配了私用区码位**（说明是真实存在、需专为造字的字形），
**却无法给出隶定**。
**这与 §一 的 9 条性质完全不同**：那 9 条《合集》给出了可读的通用汉字，只是 OBIMD 未编码；
本字《合集》自己也读不出。

### 构形（摹本 4 形 ＋ 原拓目验）

```
      ╱╲          ← 顶部：交叉／枝杈形
     ╱  ╲
    ╱____╲        ← 中部：三角／帳篷形轮廓，内有交叉笔画
    │ ╳  │
    │    │
    ╱╲  ╱╲        ← 下部：两笔分叉
```

**原拓核验**（《合集》5250，[原拓放大图](figures/rub_005250_zoom.png)）：
拓片所见与摹本结构一致，且更清晰——**中部在原拓作三角形／帳篷形，摹本规整化为方框**。

### 已排除的对照字

| 字 | 结论 |
|---|---|
| **奭**（25 次） | **形态最接近**（交叉顶＋两臂＋两侧各一物＋双腿）。但奭两侧物作圆形／手形，本字作下垂弯钩；且奭不作动词 |
| 舞（54 次） | 手部作「爪」形（三指），本字是曲笔下垂 |
| 木／桑／禾／米／東／朱／未 | 排除：下垂笔画方向不符 |
| 目／見／望／省 | 排除：不是眼形（**本仓库曾误判为「目」，已修正**） |
| 天／大／夫／文／立 | 排除：无横枝 |
| 余 | 排除：余是帳篷形＋中柱，骨架不同 |

## 四、本仓库已证实的限制

| 结论 | 数据 |
|---|---|
| **字形相似度度量在本语料上无判别力** | 同字不同形 IoU：中 0.151、史 0.068、目 0.181；跨类最高 IoU：冊 0.241。**同量级** |
| 摹本图像检索（严格同分布） | top-1 **32.8%** |
| 原拓按边界框切字 | top-1 **6.0%**（低于随机） |
| 自动对齐准确率 | **44%**（故本仓库不采信自动结果） |
| **摹本会规整化磨损处** | <img src="glyphs/gx21ndp7yy.png" alt="字形" height="22" align="middle"> 中部：原拓作三角形，摹本作方框。**构形判断必须回到原拓** |
| 被证伪的假设 | <img src="glyphs/gx21ndp7yy.png" alt="字形" height="22" align="middle">=彡、<img src="glyphs/gx21ndp7yy.png" alt="字形" height="22" align="middle">=率、<img src="glyphs/gx21ndp7yy.png" alt="字形" height="22" align="middle">=天（三个均见 [findings/](findings/)） |

**根本限制**：甲骨文生僻字的**目验辨认**需长期专业训练。本仓库作者能在原拓上辨认
「王」「貞」「卜」，但**无法可靠辨认结构复杂的待考字**——而待考字全部是生僻字。
这不是可规模化的统计方法所能替代的。**因此本仓库未能考释出任何一个字。**

## 六、诚实声明

**本仓库不是一个成功的考释。** 它包含：

- ✅ 一项完成的数据集质量筛查（**9 条已逐字核实**的编码缺失）
- ✅ 一个确证的真未释字（<img src="glyphs/gx21ndp7yy.png" alt="字形" height="22" align="middle">），**但未给出读法**
- ✅ 七套字形度量的否定性结果
- ✅ 两个可直接复用的公开数据获取途径
- ❌ **未达成**：对任何一字构建「甲骨→金文→篆字形链 ＋ 辞例验证 ＋ 音韵通假」三类完整证据链

作者欢迎具备古文字学训练的研究者接手 [handoff/](handoff/)。
