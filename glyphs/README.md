# 字形图目录 / Glyph Images

本目录共 **135 张**甲骨文字形图，用于在 Markdown 中显示**无法用文本表示**的字形。

## 为什么需要它

甲骨文字形**不在 Unicode 编码平面内**：

| 数据源 | 编码方案 | 码位范围 |
|---|---|---|
| OBIMD | 私有区（PUA-A） | U+F0000 区，41,686 个码位 |
| 殷契文渊 | 私有区 | U+60000 区，6,437 个码位 |

两套编码**互不相通**，且都不在标准 Unicode 中，因此字形无法以文本形式呈现。
本仓库正文中凡出现未释字，均以本目录的行内图片显示。

## 文件命名

文件名 = **OBIMD 内部编号**（label），例如：

- `gx21ndp7yy.png` — 本仓库重点考证的未释字 󺡅（54 次，事何類专有）
- `dsv4lhwhn7.png` — 《合集》17382 中 OBIMD 标为未释、实为「娩」的字
- `qyg9g9hii5.png` — 《合集》31983 中 OBIMD 标为未释、实为「西」的字

## 图片来源与处理

| 项 | 说明 |
|---|---|
| 来源 | OBIMD `subchar_images.zip`（摹本字形，CC-BY-4.0） |
| 处理 | 墨迹外框裁剪 → 等比缩放至 64×64 → 二值化（黑白） |
| 底 | 白底黑字（便于在 GitHub 明暗两种主题下显示） |

**注意**：这是**摹本**，不是原拓。摹本对磨损处会作规整化处理
（本仓库已抓到一例：󺡅 的中部在原拓作三角形／帳篷形，摹本作方框）。
凡涉及构形判断，应回到 `../data/rubbings/` 中的原拓核验。

## 索引

`glyphmap.json` 记录「字形字符 → 图片文件」的对应关系，供脚本使用。
其中值为 `null` 的条目表示该字形无对应图片（多为站点私有码位）。
