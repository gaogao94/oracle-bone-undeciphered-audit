# 原拓核验方法，及其揭示的根本限制

编制：2026-10-03

> 本文报告两个结果：**一项新建立的方法能力**，以及**该能力揭示的一项根本限制**。
> 后者比前者重要。

---

## 一、新建立的能力：原拓可公开取得

《甲骨文合集》图版可由公开释文库直接下载，URL 格式为：

```
https://pic2.39017.com/jgwhj/<册号>/00<片号>.png
册号为 1–13，片号补零至 6 位。
例如《合集》17382 → https://pic2.39017.com/jgwhj/1/017382.png
```
**本会话前十二轮的全部字形判断均基于 OBIMD 的摹本**（`subchar_images.zip`），
从未核验原拓。这是方法上的一个缺口，本轮补上。

已下载并核验的拓片（14 片）：
5250、5252、5253、5254、5259、5305、5326、17382、3209、2454、5373、31983*、32513*、33286*
（带 * 者该站未收录，需另寻来源）

## 二、摹本与原拓的差异（已抓到一例）

以未释字 <img src="../glyphs/gx21ndp7yy.png" alt="字形" height="20" align="middle">（《合集》5250，事何類）为例：

| 部位 | 原拓所见 | OBIMD 摹本 |
|---|---|---|
| 顶部 | 交叉／枝杈形 | 同 |
| 中部 | **三角形／帳篷形轮廓** | **规整化为方框／椭圆** |
| 下部 | 两笔分叉 | 同 |

**摹本对磨损处作了规整化处理。** 这是摹本通例，但意味着：
**摹本不能作为构形判定的唯一依据**，凡涉及中部构件形状的判断都必须回到原拓。
本会话早前把该字中部认作「目」形，即属此类误判。

## 三、根本限制：我无法可靠地辨认原拓字形

本轮我按上述方法取到《合集》17382 的原拓并放大目验，
该片释文为「鼎（貞）：…二月娩，不其…生。」，其中「娩」即 OBIMD 标为未释的 <img src="../glyphs/dsv4lhwhn7.png" alt="字形" height="20" align="middle">。

**核验未能完成。** 原因是：
1. 拓片历经三千年，笔画多有残泐、粘连
2. 甲骨契刻线条细劲，同一构件在不同拓片上形态差异大
3. 我能在拓片上认出结构简单、出现频繁的字（如「王」「貞」「卜」）
4. 但**无法可靠地辨认结构复杂的生僻字**——而待考字恰恰都是生僻字

这不是数据问题，也不是方法问题，**是能力问题**：
甲骨文的字形辨认需要长期的专业训练，非本会话所能具备。

## 四、这一限制的后果

本会话此前把失败归因于「缺数据、缺判据」。**这个归因是不完整的。**
即使三类数据齐备（类组字形表、部件分解表、原拓），
**最后一步——目验字形并判断「字形之无忤」——仍然依赖我本人不具备的专业能力。**

这解释了本会话反复出现的模式：
```
提出假设 → 用可规模化的方法检验 → 证伪 → 修正 → 再提出假设 → …
```
十一轮里我从未走完一次完整的考释，因为**最后一步我做不了**。
前面所有轮次的失败，根子在这里，而不全在数据。

## 六、结论

1. **本会话未达成目标。** 目标要求的是达到中国文字博物馆一等奖水平的考释论文，
   即对至少一个未释字构建「甲骨→金文→篆字形链 ＋ 辞例验证 ＋ 音韵通假」
   三类完整证据链。本会话未完成任何一字的此类论证。
2. **根本原因是能力限制，而非仅数据限制。** 原拓核验这一轮的实践表明：
   即使数据齐备，甲骨文生僻字的目验辨认仍需长期专业训练，
   这不是可规模化的统计方法所能替代的。
3. **已有的产出具有独立价值**：桥接方法、原拓获取途径、编码缺失筛查、
   真未释字清单。这些可作为专业研究者工作的**前置工具**。
4. **建议**：本课题若继续，应由具备古文字学训练的研究者主持，
   本会话的产出作为其数据准备与工具支持。
