# 未释字 <img src="../glyphs/gx21ndp7yy.png" alt="字形" height="20" align="middle">（gx21ndp7yy）的构形复核

编制：2026-10-03

> **本文修正本人早前的一个错误判断。** 早前把该字的中部构件认作「目」，
> 经放大目验与系统对照后，**该判断不成立**。构形应为「木」类。

---

## 一、修正

| | 早前判断 | 复核后 |
|---|---|---|
| 中部构件 | 「目」形 | **「木」形（竖干＋横枝）** |
| 整体 | 人形＋目状头部 | **木形＋两侧下垂笔画＋下部双腿** |
| 依据 | 低分辨率缩略图 | **放大目验（图 Q、图 R）** |

教训：**低分辨率缩略图会导致构件误判。** 字形判定必须以放大图为准。

## 二、复核后的构形描述

据 4 个字形放大目验（图 Q 第一行、图 R 第一行）：

| 部位 | 特征 |
|---|---|
| 上部 | **竖干，贯中** |
| 中部 | **一横（横枝）** |
| 横枝两端 | **各有一笔向内下垂**（弯钩状） |
| 下部 | **双腿分叉** |

这一结构属于**「木」类**（竖干＋横枝＋下肢），而非「目」类。

在 OBIMD 已释字中，「黍」「禾」在部分构件上近似，但不完全符合。

## 四、辞例与语法位置（不变）

| 项 | 值 |
|---|---|
| 出现次数 | 54 |
| 类组 | **事何類专有**（廪辛—康丁） |
| 前邻 | 王（16 次） |
| 后邻 | 叀（22 次） |
| 核心套语 | **「貞 王 <img src="../glyphs/gx21ndp7yy.png" alt="字形" height="20" align="middle"> 叀（惠）吉」**（22 例） |
| 语法位置 | 「王」与判断语「惠吉」之间 → **动词位或状态词位** |
| 《合集》能否隶定 | **不能**（私用区 U+E123／U+E124 占位） |

**语法位置（动词）与构形（木类）之间存在张力**：
若本字属「木」类名物字，则「王 <img src="../glyphs/gx21ndp7yy.png" alt="字形" height="20" align="middle"> 惠吉」当解为「王【用某木／行某事】，惠吉」。
卜辞中「王」后接名物再作判断的句式确有其例（如「王其田」「王往」），
故不能排除本字为名物字或由名物引申的动词。

## 五、结论

1. **修正：本字非「目」类，而是「木」类。** 判定性特征为
   「竖干＋横枝＋**横枝两端向内下垂**＋下肢」。
2. 本字确证为**学界真正未释**（《合集》亦无法隶定，用私用区码位占位）。
3. **仍无读法。** 「黍」「禾」在部分构件上近似，但均不完全符合；
   在缺乏部件分解数据与事何類专门字形表的情况下无法进一步收窄。
4. 本字是干净的考释题目：54 次、4 形、22 例固定套语、类组单一、
   且不受「数据集编码缺失」问题污染。
