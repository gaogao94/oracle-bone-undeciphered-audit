# 甲骨文未释字 AI 辅助考释：方法与可运行原型

编制：2026-10-02 ｜ 语料：OBIMD（CC-BY-4.0，10,077 片逐字标注）

> **本方法的目标不是"让 AI 直接读出字"，而是把前人获奖考释的论证流程机械化，产出可复核、可证伪的候选与证据链。** 最终判定权保留给人——这既是学术要求，也是中国文字博物馆设奖公告的硬性规定。

---

## 第一部分　把判据翻译成算法

### 1.1 前人是怎么赢的（三项一等奖的实际结构）

| 案例 | 主证 | 次证 | 是否依赖音韵 | 决定性的那一步 |
|---|---|---|---|---|
| 蒋玉斌「蠢」 | **字形** | 辞例 + 音韵 | 是（屯→春→蠢） | 用**类组**找到「春」所从声符「屯」的中间形态，把两个看似不同的形连起来 |
| 陈剑「徹」 | **辞例** | 字形 | 否 | 「辞例极相似 + 类组分布互补」——即**替换相容** |
| 王子杨「阱」 | **偏旁** | 辞例义类 | 声符系列内证 | 「歺＋井/凵」偏旁拆解 + 与《说文》形体全同 |

**共同点**：都不是"灵光一现"，而是**引入了一个新的判定维度**（类组、类组互补、偏旁规律），让原本无法判定的问题变得可判定。

### 1.2 判据 → 算法步骤

| 前人判据 | 算法化形式 | 本原型是否可运行 |
|---|---|---|
| 「孤证不立」 | 出现次数门槛 + 语境信息量门槛 | ✅ 已实现 |
| 辞例推勘 | 分布替换检验（同槽位候选） | ✅ 已实现 |
| 类组差异 | 需要卜辞分组标签 | ❌ OBIMD 无此字段（**最大缺口**） |
| 偏旁分析 | 字形部件分解 + 与已释字同族 | ⚠️ 需字形库映射或图像模型 |
| 音韵（声符链） | 上古音（声纽＋韵部）相容性过滤 | ⚠️ 部分实现（zdic 抓取成功率 37%） |
| 历史考证 | 传世文献对读 | ✅ 可外部接（人工/LLM） |
| 「孤证不立」的反面 | 平行辞例检验（异体/借字假设） | ✅ 已实现 |

## 第二部分　流水线

```
阶段 0  语料准备
        OBIMD → 按 OrderNumber 重建辞例序列 → 字形类频次
        产出：20,921 条可分析辞例

阶段 1  可考性筛选（对应「孤证不立」）
        匿名字形 = 有字形类但无隶定
        剔除：出现 1 次且无语境可读性的；残泐占位
        ↓

阶段 2  辞例证据画像
        对每个候选提取：语法槽位分布、左右邻字分布、所在辞例的完整度
        ↓

阶段 3  两条并行的证伪路径
        3A 替换相容检验：JS 散度 / 平滑对数似然 → 同槽位候选
        3B 平行辞例检验：同长度、其余位置逐字相同、同位为已知字
            → 直接产出「异体 / 借字」假设
        ↓

阶段 4  音韵与字形交叉过滤
        上古音（声纽＋韵部）相容性；声符族归属
        （偏旁族需接字形数据，见第四部分）
        ↓

阶段 5  假设回查与证据装配
        把假设读法代回全语料，检验形成的辞例是否为已知套语
        按「形 / 辞例 / 音」三类证据是否齐备打分
        输出：候选 + 完整证据链 + 置信度 + 反证 + 供专家核对的片号
```

## 第三部分　原型实测结果

### 3.1 语料基本盘

| 指标 | 数值 |
|---|---|
| 甲骨片 | 10,077 |
| 重建辞例 | 20,921（均长 4.4 字，最长 34） |
| 字形类 | 1,730 |
| 其中**匿名**（无隶定） | **243** |
| 已释且有对应字 | 1,487（其中 ≥20 次的 351 个，覆盖 93.6% token） |

### 3.2 你的三个提法，逐个实测

#### 提法一：「出现了有没有规律？」

**实测：规律性弱。** 161 个 hapax 的 ±2 字框架共 159 种，其中被 ≥2 个 hapax 共用的只有 **4 种（2.5%）**。也就是说，**单看句式模板，hapax 之间几乎没有互相印证**。

但换个角度就成立：它们的**句式类型**高度集中（卜辞、贞辞、纪日），也就是说"位置角色"是有规律的，只是具体搭配各不相同。

#### 提法二：「它是在已解释的字中间出现的吗？」

**实测：是的，而且比例很高。**

| | 数量 | 占比 |
|---|---|---|
| 左右邻皆高频已识字 | **131** | **81.4%** |
| 一侧为高频已识字 | 22 | 13.7% |
| 两侧皆非 | 8 | 5.0% |

**95% 的 hapax 至少一侧被高频已识字包围。** 这直接支持你的判断：它们多数不是孤立怪字，而是嵌在可读语境里的低频成分。

典型样本：

```
丁 酉 卜 古 貞 □ 執 寇      貞 于 □ 寧 𢽝      壬 申 卜 王 方 其 □ 圍 八 夕
戊 戌 卜 殻 貞 戉 㝵 方 □ 翦    貞 □ 取 射        乙 亥 卜 □ 以
```

#### 提法三：「偏旁部首和已解释的字有相关性吗？」

**数据结构支持这条路，但本原型接不上。** 殷契文渊字形库以 **196 个部首（BSBM）** 组织 14,695 行字形，天然构成"偏旁族"（最大族 449 个字形）。这是现成的偏旁分析底座。

**问题**：殷契文渊用内部字形码（ZKBM），OBIMD 用哈希标签（如 `xkubtjk815`），**两边无交叉引用**，所以无法把 OBIMD 的 hapax 映射到部首族。

**替代方案**：直接用《合集》释文（国学大师在线可遍历）+ 字形图像模型做部件分解，或人工抽样建映射表。

### 3.3 最有价值的一条：平行辞例检验

**严格检验**（同长度、**其余位置必须全部是已释字**、同位为已释字）：

> **161 个 hapax 中，26 个（16.1%）找到了合格的平行辞例。**

这 26 个直接构成"**异体 / 借字**"假设，是当前最可推进的一批：

| 未释字 | 本字辞例 | 平行辞例推出的同位字 | 完整串在语料中出现 |
|---|---|---|---|
| 󵖪 | `卜 爭 □` | **貞**（6460 次） | 1 |
| 󴲍 | `己 □` | **丑**（602 次） | 4 |
| 󹛛 | `癸 亥 卜 □ 貞 旬 亡` | **史**（173 次） | 1 |
| 󹥠 / 󴷨 | `叀 □ 令` | **畢**（87 次） | 3 |
| 󵀈 | `隹 㞢 □` | **雨**（1384 次） | 1 |
| 󾒻 | `□ 以` | **貞**（6460 次） | 5 |
| 󾣲 | `自 □` | **西**（62 次） | 3 |
| 󻟟 | `不 □` | **隹**（314 次） | 2 |
| 󾤶 | `于 □` | **帚**（178 次） | 1 |
| 󴆻 | `勿 □` | **于**（2291 次） | 1 |
| 󿧠 | `□ 且 乙` | **來**（346 次） | 1 |
| 󹲙 | `辛 卯 卜 尞 于 □` | **䖵**（10 次） | — |

### 3.4 必须说清楚的局限（否则就是学术不端）

**「同槽位」不等于「同字」。** 平行辞例只证明"这个位置可以放某个字"，不证明"这个未释字就是那个字"。

三个具体的反例风险：

1. **范式效应**：`叀 □ 令` 推出「畢」，但任何能进入这个范式的字都会得到同样结果。
2. **地名/人名位**：`于 □` 推出「帚」，但「于＋地名」的槽位可以容纳几百个字。
3. **卜辞套语**：`卜 爭 □` 推出「貞」，但「卜爭貞」本身就是固定格式，套语内部的位置对字形的约束很弱。

**所以正确的位置是**：这是一份**排序后的假设清单**，不是释读结论。它把 161 个无从下手的 hapax 压缩成 26 个有明确验证路径的假设，每条假设都附带可核对的片号。

**而且它对应的是奖项体系里的二等奖（对存争议字作新释读），不是一等奖（破译未识字）。** 这个定位要说清楚。

## 第四部分　要真正闭环，还缺什么

| 缺口 | 影响 | 补法 |
|---|---|---|
| **类组标签** | 两项一等奖的决定性维度（蒋用类组找中间环节、陈用类组互补）。OBIMD 完全没有 | 从《合集》片号 + 学术出版物补类组归属；或与社科院/首师大合作取数 |
| **字形部件分解** | 偏旁分析（唐兰四法中最可靠的一路）无法运行 | 接字形图像模型，或人工建 ZKBM ↔ OBIMD 映射表 |
| **完整上古音表** | zdic 抓取成功率仅 37%，音韵过滤不完整 | 换数据源（东方语言学 / 白一平-沙加尔系统），或改为离线音韵表 |
| **《合集》释文** | 只有 1 万片语料；《合集》41,956 片释文可遍历但无开放授权 | 用 OBIMD 已授权部分；或向中华书局古联申请 |
| **三级审稿流程** | 设奖要求 2 名正高推荐 + 专家委员会鉴定 | **不可替代，必须走人工** |

## 第五部分　这套方法的诚实定位

**它能做**：
- 把 243 个匿名字形按"可考性"排序，指出哪 26 个有明确的验证路径、哪 30 个当前无解；
- 为每条假设自动装配证据链（辞例原文、片号、同位字、音韵信息）；
- 批量执行"假设回查"——把假设读法代回全语料，检验是否产生已知套语。

**它不能做**：
- 替代字形审定。没有字形证据，任何读法都过不了专家委员会；
- 处理那 30 个评分 <30 的 hapax（语境里没有足够的已释字支撑）；
- 解决类组问题——而类组恰恰是近年两项一等奖的胜负手。

**一句话**：这套方法把"从 243 个未知里挑出可下手的"，从靠经验变成了可复现的流程；但"挑出来之后能不能定"，仍然取决于字形和类组这两类本原型还接不上的证据。
